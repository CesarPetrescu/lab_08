# Sorting Algorithms for Integer Arrays

This lab contains implementations of common sorting algorithms written in C:

- **Bubble Sort** (`bubble-sort.c`)
- **Merge Sort** (`merge-sort.c`)
- **Radix Sort** (`radix-sort.c`)

Each program reads an array of integers from standard input, sorts it, and
prints the result.

Compile any of the programs using `gcc`:

```bash
$ gcc bubble-sort.c -o bubble-sort
$ gcc merge-sort.c -o merge-sort
$ gcc radix-sort.c -o radix-sort
```

Run the resulting executable to provide the input.
